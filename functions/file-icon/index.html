文件图标更换器

上传一张 PNG/JPG，把它变成目标文件 / 文件夹的新图标（需后台）

正在检测后台…
🖼️ 把 PNG / JPG 图片拖到这里，或点击选择

原图与新图标会一起保存到目标所在文件夹，请勿事后删除（否则图标回退默认）。

处理规则：
① .lnk 快捷方式 → 改它自己的图标字段（指向不变），图标存到它指向的文件/文件夹所在目录；
② 文件夹 → 写 desktop.ini 直接换图标，图标存到该文件夹内；
③ 普通文件 → Windows 限制无法单独改本体图标，会在同目录生成带新图标的 .lnk 快捷方式（双击 = 打开原文件）。
图标文件命名跟随目标名，如 Photos（文件夹）→ Photos.ico。
